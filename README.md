# 主 Skill 介绍

## 名称

`kaoyan-politics-mistake-analysis`

## 定位

一个面向考研政治个人复习的学习诊断 Skill。

它不把错题重新讲一遍，而是把错题转化为：

- **知识漏洞**：教材中哪个概念没有真正掌握
- **关系漏洞**：谁决定谁、谁反作用于谁、哪个阶段对应哪个政策没有分清
- **判断漏洞**：根本、主要、首要、唯一、决定、始终等限定词是否被抬高
- **方法漏洞**：多选漏选、错选、材料方向判断错误、题号错配、算题模板错误
- **复习动作**：下一轮具体背什么、重做什么、如何验收

## 为什么适合发布

### 1. 输入范围宽

可以接收 720、肖1000、历年真题和模拟题，不依赖某一种题库。

### 2. 输出结构稳定

所有模块统一使用“考点结论—我错在哪—真题怎么考—下次怎么做”的四段结构，便于长期积累和回访。

### 3. 有证据链

错题判断、真实题号、教材结论、真题原文和正确率分母分别有对应来源，不鼓励凭印象补题。

### 4. 有隐私边界

个人错题和公共真题分析分开，考生之间分开，公开发布包不携带真实姓名、私人路径和原始错题。

### 5. 不把“粗心”当诊断

Skill 会进一步追问：是概念混淆、关系方向、限定词、历史阶段、多选筛选还是材料匹配问题，并把它改写成考场动作。

## 推荐用法

### 从一份错题导出件开始

```text
使用 kaoyan-politics-mistake-analysis。
考生：A
模块：马原
来源：720
输入：<错题导出文件>
上游资料：<教材、720解析、近年真题、时政资料>
请按个人错题分析，不要写成通用真题分析。
```

### 继续做回访

```text
读取上一批提分手册和回访清单。
只分析本次仍然做错的题，判断是旧错因复发还是新错因。
不要覆盖原批次统计。
```

## 不适合的场景

- 只做公共真题分析
- 只做某道题的答案解释
- 需要跨考生排名或比较
- 没有任何个人错题，却要求判断个人薄弱环节

```text
5. 确认输出仍然保持考生隔离和上游只读
```
