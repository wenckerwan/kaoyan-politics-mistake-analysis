# 隔离、证据与安全边界

## 数据流

```text
错题导出件 / 个人笔记
          │
          ▼
个人错题分析 Skill
          │
          ├── 提分手册
          ├── 回访清单
          └── 可选索引记录

教材 / 题库 / 真题 / 时政资料
          │
          └── 只读引用，不回写
```

## 不可越界

- 上游真题分析不能读取本 Skill 生成的个人错因
- 个人 A 的错题不能进入个人 B 的统计
- 朋友的错题不能进入本人的学习档案
- 不把私人姓名、绝对路径、原始 PDF 或隐私信息写入公开 Skill 包
- 不把个人正确率当作群体规律

## 证据声明

每条重要结论应该能回答“依据是什么”：

| 结论类型 | 首选依据 |
|---|---|
| 是否为错题 | 导出件中的我的答案和正确答案，或用户对空答案语义的明确说明 |
| 题目内容 | 导出件原题，缺失时题库试题册 |
| 标准答案 | 导出件解析，缺失时题库解析册 |
| 教材结论 | 教材或解析册刷题笔记 |
| 真题原文 | 真题原卷或真题索引 |
| 正确率分母 | 题库按模块、章节、题型核出的真实题量 |

## 缺失信息策略

- 能补证据就补证据
- 不能补证据就标“待核”
- 不能为了完成报告而编造题干、答案、页码、引用或考生选择
- 用户给出明确的导出语义后，优先采用用户语义并在批次口径中记录
