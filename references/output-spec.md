# 输出规范

## 1. `提分手册_<模块>.md`

### 文件头模板

```markdown
# <模块>提分手册（考生 <代号>）

> **这是什么**：你 <N> 道<模块>错题的考点笔记，不是逐题答案汇总。
> 目标是回答：这些错题如何让我下一次做对。
>
> **重做**用 `回访清单_<模块>.md`。

## 本批数据

| 项目 | 数值 |
|---|---:|
| 小程序导出 | <N> 题 |
| 剔除答案一致题 | <N> 题 |
| 实际错题 | <N> 题 |
| 题库真实题量 | <N> 题 |
| 正确率 | <N>% |
```

### 章节模板

```markdown
# <章节>（<错题数> 道）

## 一、考点结论

用短句、表格和对照关系提炼教材结论。

## 二、我错在哪

> 第一类（<命中数> 道）：<个人错因>

| 我犯的错 | 正解 |
|---|---|
| ... | ... |

## 三、真题怎么考

### ① <年份>·<题号>（单选/多选）—— <一句话考点>

> <可核验真题原文>

**考点提示**：<与个人错题的对应关系和迁移方法>

## 四、下次怎么做

> <一个具体动作>
```

### 文件尾模板

```markdown
# 附录一　做题方法清单

| 动作 | 命中次数 | 下次怎么执行 |
|---|---:|---|
| ... | ... | ... |

# 附录二　真题设问地图

| 真题标签 | 真题题数 | 我的错题落点 | 复习结论 |
|---|---:|---|---|
| ... | ... | ... | ... |
```

## 2. `回访清单_<模块>.md`

每道题保留：

- 题库真实题号
- 题干
- 选项
- 原始答案标记（有证据才写）
- `这次：☐ 对　☐ 错`

缺少“我的答案”时：

```markdown
**上次**：我选 **（导出时已删）** ｜ 正确 **<答案>**
**这次**：☐ 对　☐ 错
```

## 表达要求

- 结论优先，短段落优先
- 重要关键词加粗
- 表格优先于长段落
- 解释个人问题，不羞辱考生
- 不把“粗心”当作最终原因
- 不用未经核验的引号冒充教材或真题原文
